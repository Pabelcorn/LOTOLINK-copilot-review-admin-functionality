🎨 UI Components

Banca Configuration Tab includes:

  • Loterías Section: Grid with toggle switches for each lottery (Loteka, Leidsa, Nacional, Real, Anguila, Primera). Each card shows commission override, daily limit, and max per bet fields.
  • Sorteos Section: Tables grouped by lottery showing draws with checkboxes for enabling/disabling, time, days of week, and early close minutes.
  • Precios Section: Table with columns for Lottery, Bet Type, Min/Max amounts, Increment, Multiplier, Max Prize, and Enabled checkbox. Includes buttons for "Apply Default Prices" and "Copy from Another Banca".
  • Límites Section: Form to add number limits with fields for Lottery, Draw, Bet Type, Number, and Max Amount. Table shows current limits with sales data.
  • Bloqueados Section: Form to block numbers with fields for Lottery, Draw, Bet Type, Number, Reason, and Block Until date. Table shows currently blocked numbers.

Propietarios Tab includes:

  • Registration form with personal data (first name, last name, cédula, RNC, email, phone, business name)
  • Banking information section (bank, account type, account number)
  • Default commission percentage field
  • Table listing all owners with their bancas count and actions
